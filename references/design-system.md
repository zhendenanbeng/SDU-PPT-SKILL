# 美术规范（design system）

模板里的每一页都遵守这份规范。复制模板页面时它自动成立；只有在新建自定义页面、调整位置或补充图形时才需要查这里。
单位：厘米（cm），幻灯片 16:9，宽 33.867 cm × 高 19.05 cm。1 cm = 360000 EMU。

## 1. 栅格与固定元素

| 元素 | 位置 / 尺寸 |
|---|---|
| 左右边距 | 2.0 cm（内容区 x：2.0 – 31.87 cm，宽 29.87 cm） |
| 内容区纵向 | 3.6 – 17.2 cm（高 13.6 cm）；底部 17.75 – 18.45 cm 为页码带 |
| 正文页标题 | 左上 x 2.0、y 0.78，宽 24.27、高 1.7 cm；与右上 Logo 垂直居中对齐 |
| Logo | 右上，右边缘对齐 31.87 cm，顶部 0.9 cm，宽 4.3 cm；白底页用红色 Logo，红底/照片页用白色 Logo |
| 页码 | 右下，右对齐 31.87 cm，11 pt 宋体灰色；红色装饰压底的页面改为白色 |
| 两栏 | 两栏间距 1.6 cm（每栏 14.135 cm） |
| 卡片 / 面板间距 | 0.8 cm（三栏卡片每张约 9.42 cm 宽） |
| 图片拼贴间距 | 0.4 cm |
| 结论框 | 通栏（x 2.0，宽 29.87），高 2.4–2.6 cm，放在页面下部 |

规则：同类页面的标题位置必须一致；新增元素的左边缘对齐 2.0 cm，右边缘对齐 31.87 cm；相邻块之间的间距只用
0.4 / 0.8 / 1.2 / 1.6 cm 这几档，不随手取值。

## 2. 字体与字号

- 标题字体（主题 major）：**Noto Serif SC**（思源宋体），用于标题、章节号、大数字、标签、序号。
- 正文字体（主题 minor）：**Noto Sans SC**（思源黑体），用于正文、说明、图表文字。
- 中英文、数字、符号都跟随这两套字体，不另设西文字体。所有文字都引用主题字体（`+mj` / `+mn`），
  这样在「设计 → 变体 → 字体」里改一次就能全局替换。

| 用途 | 字号 | 样式 |
|---|---|---|
| 封面标题 | 60 pt | 宋体加粗、白色、字距 4 pt；超长自动缩小 |
| 结束页标题 | 66 pt | 宋体加粗、白色、字距 6 pt |
| 章节号 / 章节标题 | 96 / 40 pt | 宋体加粗、白色 |
| 正文页标题 | 30 pt | 宋体加粗、山大红 |
| 大数字（关键数据） | 54 pt + 单位 24 pt | 宋体加粗、山大红 |
| 小标题 / 要点标题 | 18 – 22 pt | 黑体加粗、深灰 |
| 正文 | 18 pt（密集时 16 pt） | 黑体、行距 150%、两端对齐、首行缩进 2 字 |
| 卡片说明 / 列表 | 15 – 16 pt | 黑体，次要信息用灰色 |
| 注释、图源、数据来源 | 11 – 13 pt | 黑体灰色 |

中文排版：标点不出现在行首，单字不成行，数字与单位不拆行（必要时改写或用 `fit()` 收紧）；
两字标签与四字标签对齐时用全角空格（「校　　训」）。

## 3. 颜色（主题色）

| 槽位 | 色值 | 用途 |
|---|---|---|
| `accent1` / `dk2` | `#9B0D14` 山大红 | 标题、强调、主系列、序号圆、表头 |
| `tx1`（dk1） | `#3B3B3B` | 正文 |
| 次要灰 | `tx1` lumMod 75% + lumOff 25%（约 `#6B6B6B`） | 说明、标签、注释 |
| 细线灰 | `tx1` lumMod 15% + lumOff 85%（约 `#DDDDDD`） | 分隔线、网格线 |
| `bg2`（lt2） | `#F0EEEC` 浅暖灰 | 面板、图片框、结论框、斑马纹 |
| `accent2` | `#4A4A4A` 炭灰 | 第二系列、对比项 |
| `accent3` | `#A6A6A6` 中灰 | 第三系列、未开始状态 |
| `accent4` | `#CF9C9F` 浅玫红 | 第四系列 |
| `accent5` | `#6E0A0F` 深红 | 深色层次（如框架图底层） |
| `accent6` | `#E2DDD8` | 第六系列、甘特计划条底色 |

一页里红色只用来强调最重要的那一处，比如一个强调卡片、一个结论标签、一个主系列。
照片背景统一叠加山大红渐变蒙版（不透明度 84% – 94%）。

## 5. 图表、表格、图片

- **图表**：一律平面化，不用 3D；系列颜色依次为 accent1、accent2、accent3……；网格线用细线灰，坐标轴文字 12 pt 灰色；
  图表标题 14 pt 加粗放左上，图例放右上；环形图孔径 56%，扇区之间用白色分隔，标签只显示百分比，
  浅色扇区上的标签改用深色字。
- **表格**：表头山大红底、白色加粗字；数据行斑马纹（`bg2`）；横向细线、无竖线；
  重点行（本文方法 / 本研究）红色加粗，上下加红线；表注 12 pt 灰色放在表格下方。
- **图片**：按框的比例裁切填满，不拉伸变形；人物照片用圆形（`team` 页）；
  照片作背景时必须叠加红色蒙版，保证白字清晰可读；图片来源写在图下方或备注里。

## 6. 禁用做法

- 文字阴影、描边、渐变字；3D 图表、斜面和发光效果；
- 标题下面的装饰横线；卡片或页面边缘的装饰色条；
- 模板之外的字体，或在主题色之外随意取色（彩虹配色、默认 Office 蓝）；
- 正文居中（只有标题和简短说明可以居中）；
- 用连续空格对齐或缩进（改用段落缩进或全角空格对齐标签）；
- 一页塞进多个结论，或把大段讲稿直接放到页面上（讲稿写进备注）。
