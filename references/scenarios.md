# 场景与推荐页序

括号里是模板页面的 key，用 `deck.add(key)` 复制。页数按 1.5 – 2 分钟一页估算。
同一种页型可以重复使用（比如连续几页 `pictext` 展示不同结果）。

## 组会汇报（课题组周会，8 – 12 页，10 – 15 分钟）

目的：让导师和同学快速知道你做了什么、卡在哪、下一步做什么，所以重点放在问题和讨论上。

1. 组会封面（`mcover`）：标题写「第 N 周组会汇报」，副标题写课题组和本周主题。
2. 本周工作概览（`weekly`）：已完成 / 进行中 / 下周计划三栏，每项一句话，可带进度百分比；底部「本周小结」写一句总判断。
3. 实验结果与分析（`result`，可重复）：左边写实验设置、结果观察、下一步，右边放结果图。
   需要对比数据时用 `bar` / `line` / `table`。
4. 问题与讨论（`issues`）：每个问题写现象和已尝试的办法；右侧列出希望讨论的具体问题，问题越具体越容易得到帮助。
5. 结束页（`close`）：副标题可写「欢迎批评指正」（中文副标题记得 `style(..., spacing=2)`）。

写作提示：结果页的标题写结论（「改进模型收敛更快」），而不是「实验结果」；
数据来源和实验设置写在页面或备注里，方便追问。

## 文献汇报（journal club / 读书报告，10 – 15 页）

目的：讲清这篇论文解决什么问题、怎么做、证据是否可信，以及对本课题有什么用。

1. 封面（`cover`）：标题用论文的核心主题（中文 ≤ 12 字），副标题写「文献汇报 · 第 N 期」。
2. 论文信息（`paper`）：英文题目、作者、期刊、时间、影响因子 / 分区、DOI、关键词、推荐理由；左侧插入论文首页截图。
3. 研究背景与问题（`text` 或 `background`）：领域痛点和本文要回答的问题。
4. 方法（`process` 或 `framework`；有原文方法图时用 `figread` 放图）。
5. 关键结果（`figread`，可重复）：一张原文图加三条解读要点，图源写清楚出处。
6. 文献评述（`review`）：主要贡献 / 不足与局限 / 对本课题的启发，底部写总体评价。
7. 多篇对比（`litcmp`）：做综述型汇报时用，最后一行写本研究，底部指出研究空白。
8. 参考文献（`refs`）→ 结束页（`close`）。

写作提示：引用原文图表必须注明来源；评述要具体到实验设置或假设，不要只写「有一定局限性」。

## 研究汇报（学术报告 / 课题汇报，12 – 20 页）

1. 封面（`cover`）→ 目录（`toc`）→ 章节页（`section`，每章一页）。
2. 研究背景与意义（`background`）。
3. 研究内容（`grid4`）或三个研究重点（`three`）。
4. 研究框架（`framework`）与技术路线（`process`）。
5. 方法细节（`text`、`twocol`、`pictext`、`figread`）。
6. 结果（`stats` 关键数据，`bar` / `line` / `donut` 图表，`table` 对比表，`compare` 方案对比）。
7. 结论与展望（`conclusion`）→ 参考文献（`refs`）→ 结束页（`close`）。

写作提示：每章开头用章节页，章节号与目录一致；每个结果页底部用结论框写「这说明了什么」。

## 进度汇报（中期检查 / 项目进展，6 – 10 页）

1. 封面（`cover`）。
2. 进度总览（`progress`）：用 `progress(tasks)` 设置任务、完成度和状态，圆环会自动计算总完成度。
3. 甘特图（`gantt`）：计划与实际对比，`now` 标出当前时间，延期一眼可见。
4. 阶段进展（`timeline`）：`timeline_done(k)` 标出已完成的阶段。
5. 关键成果（`stats`、`table`、`pictext`）。
6. 问题与风险（`issues`）。
7. 下阶段计划（`nextplan`）：近期 / 中期 / 远期，底部「需要支持」写清楚资源需求。
8. 结束页（`close`）。

写作提示：进度数字要和甘特图、时间轴一致；延期的任务要写原因和补救措施。

## 学位答辩 / 开题报告（15 – 25 页）

1. 答辩封面（`cover2`）：论文题目、答辩类型、答辩人、导师、专业、日期。
2. 目录（`toc`）→ 各章章节页（`section`）。
3. 研究背景与意义（`background`）→ 国内外研究现状（`litcmp`、`text`）。
4. 研究内容（`grid4`）→ 技术路线（`process`）→ 研究框架（`framework`）。
5. 研究方法与实验（`pictext`、`figread`、`table`、`bar` / `line`）。
6. 开题时用研究进度安排（`timeline`）和预期成果（`process` 底部的结论框）；
   答辩时用结论与展望（`conclusion`）和成果列表（`text` 或 `three`）。
7. 参考文献（`refs`）→ 致谢可用 `text` → 答辩结束页（`close2`）。

## 课程 / 讲座 / 通用汇报

封面 → 目录 → 章节页 → 从「通用 · 文字 / 图文 / 数据」三节按内容选页 → 引用金句（`quote`）可用作章节过渡或收尾 → 结束页。
介绍团队或课题组时用 `team`，展示校园或现场照片时用 `bigpic`。
